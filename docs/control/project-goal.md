# Project Goal

## Project
CareerTwin

## Product Mission
CareerTwin is an AI career companion that builds and uses real career memory (evidence) to support users across their entire career lifecycle.

It acts as both a companion and a coach, helping users make decisions and generate high-quality outputs in real career scenarios.

## Core Concept: Career Memory

- All user experiences are captured as evidence
- Evidence is structured into capabilities
- Memory improves over time through usage
- All Copilots use shared career memory

Career memory is the foundation of long-term system value.

## Product Structure (Copilot System)

- Job Copilot -> match, gap, CV
- Interview Copilot -> questions, practice, feedback
- Promotion Copilot -> promotion case, readiness
- Career Transition Copilot -> path + plan
- Performance Review Copilot -> review generation

All powered by Career Memory.

Deliver a Job Copilot experience that:

## In Scope

- Matching (fit + risk + reasoning)
- Gap identification
- Tailored CV generation
- Interview Copilot
- Memory accumulation from interactions

## Out of Scope

- Promotion / performance / transition Copilots
- Major architecture redesign
- Complex orchestration systems

---

## Non-Negotiable Principles

### 1. Memory-first system
All outputs must be grounded in real evidence.

### 2. Evidence > wording
Evidence selection matters more than rewriting.

### 3. Explainability
Users must understand WHY.

### 4. Memory growth
Every interaction should increase career memory.

---

## Dual-Core Principle

CareerTwin operates on two equally critical axes:

### Internal: Career Memory
- Every feature must build or use memory

### External: User Experience
- Every Copilot must feel:
  - highly relevant
  - non-generic
  - credible
  - useful

These reinforce each other:
Experience -> Usage -> Memory -> Better Experience

---

## Definition of Done (Phase 1)

- Matching is stable and meaningful
- CV is:
  - job-specific
  - evidence-grounded
  - ATS-safe
  - hiring-manager credible
- Interview Copilot is useful
- Memory is accumulating

## Quality Bar

- Correctness -> matches real experience
- Reliability -> consistent outputs
- Product Value -> strong perceived usefulness
- Integrity -> no hallucination
- Memory Growth -> every use improves system
